# Superstore Sales Performance Dashboard

## Project Overview
An interactive 5-page Power BI dashboard analyzing retail sales, 
profit, and customer behavior using the Sample Superstore dataset.

## Tools Used
- Power BI Desktop
- DAX
- Power Query

## Data Model
Star Schema with 1 Fact table and 4 Dimension tables
- Fact_Orders
- Dim_Customer
- Dim_Product
- Dim_Date
- Dim_Shipping

## Dashboard Pages
1. Executive Overview — KPIs, monthly trend, regional sales
2. Product Analysis — Top/bottom sub-categories, profit by category
3. Regional Performance — State-wise sales map and city table
4. Customer Segments — Segment breakdown across categories
5. Discount Impact — Discount vs profit margin scatter analysis

## Key Insights
- Tables and Bookcases generate negative profit despite high sales
- Binders carry 37% avg discount — highest in the dataset
- Consumer segment contributes 50%+ of total sales
- California and New York are the top 2 states by revenue
